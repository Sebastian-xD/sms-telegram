# SMS → Telegram

Android-застосунок, що пересилає вхідні SMS у Telegram-бота. Мінімальне навантаження: будиться лише коли приходить SMS.

**Встановлення:** завантажте [SMS-Telegram.apk](SMS-Telegram.apk?raw=1) і відкрийте на телефоні.

Оновлення далі — кнопкою «Перевірити оновлення» в самому додатку.
